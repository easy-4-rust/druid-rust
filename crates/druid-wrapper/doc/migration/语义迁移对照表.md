## 4. SQLite 真实证据

| 测试 | 真实路径 | 结果 |
| :--- | :--- | :--- |
| `sqlite_wrapper_semantics_test` direct | facade → SQLx → SQLite | 通过 |
| 同测试 bb8 | facade → bb8 lease → SQLx → SQLite | 通过 |
| 同测试 deadpool | facade → deadpool Object → SQLx → SQLite | 通过 |
| `sqlx_connection_adapter_test` | SQLx typed/prepared/tx/savepoint | 5/5 |
| `sqlx_bb8_pool_test` | bb8 return/timeout/broken | 5/5 |
| `sqlx_deadpool_pool_test` | deadpool return/timeout/closed | 5/5 |

严格结论：SQLx/bb8/deadpool 的 SQLite 主链有真实证据；RBDC 仍缺真实 SQLite
driver，Java wrapper 13 对象的配置兼容也未闭合，所以模块保持 `PARTIAL`。
