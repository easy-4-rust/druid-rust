# Druid Java → druid-rust 功能语义迁移对照表

基线：Alibaba Druid **1.2.28**（1644 个 Java 文件）。

迁移原则：**功能语义对齐，实现方式 Rust 化**。
Java 的 JDBC Proxy、反射、JMX、Spring Boot 分别映射为：装饰器、trait 对象、
metrics/tracing、Builder pattern。

状态图例：✅ 已迁移并有测试 / 🔶 语义等价但形态不同 / ✅ 已实现（路线图）/ 🚫 不迁移
