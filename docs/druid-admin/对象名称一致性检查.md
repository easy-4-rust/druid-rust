## 4. 当前命名问题

- `AdminState` 是允许的 Rust-only Router state，但必须有来源说明；
- `endpoint_list()` 不是 Java 对象，也不能替代 `MonitorViewServlet`；
- `lib.rs` 当前定义逻辑函数，违反模块门面仅声明/重导出的目标规范；
- Java DTO 必须分别建立独立 `.rs` 文件，不能合并为一个 `admin_state.rs`。

当前对象名称一致性为 0/13，语义迁移保持 `MISSING/PARTIAL`。
