## 3. 非一对一登记

| Java 对象 | 决策 | 原因 | 等价结果 |
| :--- | :--- | :--- | :--- |
| `DruidAdminApplication` | SPLIT | Rust library 与 binary 分离 | Router builder + optional main |
| `MonitorViewServlet` | PROTOCOL | Servlet 容器替换为 Axum | 相同路径、内容、状态和资源 |
| `HttpUtil` | ADAPTER | Java HTTP client 替换 | 相同请求、超时、错误、JSON |
| Spring DiscoveryClient | ADAPTER | Rust 无统一 Spring Cloud | `DiscoveryClient` trait + registry adapters |

## 4. 当前命名问题

- `AdminState` 是允许的 Rust-only Router state，但必须有来源说明；
- `endpoint_list()` 不是 Java 对象，也不能替代 `MonitorViewServlet`；
- `lib.rs` 当前定义逻辑函数，违反模块门面仅声明/重导出的目标规范；
- Java DTO 必须分别建立独立 `.rs` 文件，不能合并为一个 `admin_state.rs`。

当前对象名称一致性为 0/13，语义迁移保持 `MISSING/PARTIAL`。
