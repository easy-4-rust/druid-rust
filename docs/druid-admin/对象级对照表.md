## 2. Rust 当前对象

| Rust 对象 | Java 对应 | 判断 |
| :--- | :--- | :--- |
| `AdminState` | 无直接单一对象；Router state | RUST_ONLY 兼容门面，已有来源说明，不计入 13 个 Java 对象 |
| `DiscoveryClient` / `ServiceInstance` | Spring Cloud discovery protocol | ADAPTER SPI；具体注册中心可在模块外扩展 |
| `KubeRsDiscoveryProvider` | Kubernetes Java client | ADAPTER，使用 kube-rs |
| `ReqwestHttpClient` | Java `HttpUtil` 底层客户端 | ADAPTER，timeout/status/JSON typed error |
| `StatQuery` / `LoginRequest` | Servlet 参数 | ADAPTER，axum-valid |
| `endpoint_list()` | Rust 早期门面 | RUST_ONLY 清单；真实 Router 已存在，不再作为完成证据 |

## 4. 平台依赖映射

| Java/Spring 能力 | Rust 能力 | 规则 |
| :--- | :--- | :--- |
| Spring Boot application | Topcoat server + library Router | 不把启动器混入领域对象 |
| `ResourceServlet` | Topcoat 外壳 + Axum handler | 路由结果一致 |
| Servlet 参数校验 | axum-valid | Form/Query 在边界校验；raw legacy URL 保留 Java parser |
| Servlet runtime | Tokio | 异步任务、取消与关停进入统一验证 |
| Servlet task statistics | tokio-metrics | `/metrics`，不得替代 Druid 业务统计 |
| 节点快照传输 | prost | Rust-only 可选能力，不改变 Java JSON |
| 管理 UI | Topcoat + Axum HTML | 功能语义迁移，不声明 Java 静态字节一致 |
| Spring Cloud Discovery | `DiscoveryClient` trait + adapters | 每种注册中心独立实现 |
| Kubernetes Java client | `kube`/HTTP adapter | namespace/label/error 一致 |
| Apache HttpClient/OkHttp | typed async HTTP client | timeout/状态码/JSON 错误一致 |
| Fastjson2 | serde/serde_json | 字段名、null、数字和数组一致 |
