### 3.2 PreparedStatement setter 语义账本

| Java 签名族 | Rust 对象/API | 已保留语义 | 当前边界 |
| :--- | :--- | :--- | :--- |
| `setNull(int,int[,String])` | `PreparedInputParameter::Null` + `PreparedTypeNameArgument` | 区分无 typeName 重载、显式 null 和实际 typeName | 标量执行为 SQL NULL |
| `setBoolean/Byte/Short/Int/Long/Float/Double` | 独立 enum variant + 同名 snake_case setter | 不在池化层抹平成单一 number；重复设置覆盖同一 1-based 槽位 | Toasty SQLite 真实绑定通过 |
| `setBigDecimal/String/NString/Bytes` | nullable 强类型 variant | 保留 Decimal scale、national string 和 bytes/null | Toasty SQLite 真实绑定通过；SQLite 可在读取时规范化 decimal |
| `setDate/Time/Timestamp([,Calendar])` | `JdbcCalendarArgument` | 区分无 Calendar 重载、显式 null Calendar 与实际时区对象 | Toasty SQLite 强类型读回通过 |
| `setObject([,targetSqlType[,scaleOrLength]])` | `JdbcObject` + 可选目标 SQL 类型/scale | 三个 Java 重载不合并，标量可进入统一 Value 路径 | vendor object 仍需原生 Adapter |
| ASCII/Binary/Unicode Stream | `JdbcInputStream` + `JdbcStreamLength` | 无长度/int/long 精确区分，负长度原样保留，不预读 | 执行时显式报原生 Adapter 未实现 |
| Character/NCharacter Stream | `JdbcReader` + `JdbcCharacterLength` | 无长度/int/long 精确区分，Reader 身份与位置不被消费 | 执行时显式报原生 Adapter 未实现 |
| Blob/Clob/NClob 对象及 stream/reader | 对应 JDBC 资源对象 variant | 对象重载与流重载不混淆，nullable 和长度保真 | 原生 LOB bind 待补 |
| Ref/Array/URL/RowId/SQLXML | 独立资源 variant | 不用 String/Bytes 冒充资源；URL 是可无损标量例外 | 资源原生 bind 待补 |

所有 setter 都先验证语句/租约开放状态，再立即调用
`PhysicalPreparedStatement::set_parameter`；只有物理调用成功才更新逻辑参数槽。
因此驱动错误发生在与 Java 相同的 setter 调用点，并立即进入连接异常 sorter。
`clear_parameters` 同样只在物理 clear 成功后清空逻辑状态。执行前将 1-based 槽位
转为有序参数；任何空洞都返回 `InvalidArgument`，不会把未绑定参数伪装成 NULL。

## 6. SQLite 真实证据

`crates/druid/tests/sqlite_core_semantics_test.rs` 纵向穿过
`druid facade → DruidPool → DruidPooledConnection → statement cache →
ToastyConnectionAdapter → Toasty Driver → SQLite`，验证：

- 真实 DDL/DML/查询与参数绑定；
- PreparedStatement 真实执行和连接级缓存命中；
- 事务 rollback；
- close 后同一物理连接复用和计数；
- `COUNT(*)` 按 SQLite 运行时 INTEGER 类型解码；
- CallableStatement 明确 `UnsupportedOperation`。

SQLite 不支持存储过程、XA 和 vendor SQLState，相关语义不得标 `PASS`。

`crates/druid/tests/toasty_connection_adapter_test.rs` 直接验证 factory
metadata、六类 `Value` 参数、`last_insert_rowid()`、prepared close、完整保存点、
SQLite 只支持 Serializable、只读明确 unsupported、discard 和未知 URL scheme。
该合同已由 `druid` 默认构建执行。

#### 17. Rust 侧新增对象的语义边界

| Rust 对象 | 来源语义 | 允许新增的原因 | 禁止事项 |
| :--- | :--- | :--- | :--- |
| `PhysicalConnection` | JDBC Connection 平台能力 | Rust 内部 object-safe async SPI | 不公开池化所有权，不承载 Filter/统计 |
| `PhysicalConnectionFactory` | JDBC Driver/driver manager | native direct adapter 显式依赖注入 | 不得获取 bb8/deadpool lease |
| `ToastyConnectionFactory` / `ToastyConnectionAdapter` | 内置标准数据源 | Toasty `Driver::connect` raw connection | 不得创建 Toasty `Db` pool；SQLite 真实合同必须通过 |
| `ConnectionProvider` | DataSource 获取路径 + 外部池 wrapper | native/bridge 统一入口 | 同一租约不得嵌套两层 pool |
| `ConnectionLease`、`LeaseReturner` | pooled close/recycle | Rust 所有权与异步 Drop | 不得双重归还或静默丢弃 |
| `DruidConnectionHolder` | Java 同名 holder | Rust 所有权下由 native idle queue 与 pooled facade 移动同一个对象 | 不得再拆出第二份 idle metadata，也不得暴露为第二个公开连接 |
| `ConnectionDefaults` | holder 默认状态与 reset | Rust 值对象，避免驱动类型泄漏 | 只能作为 canonical holder 的组成，不得替代 PS cache 等未迁移职责 |
| `ConnectionRecycleDisposition` | recycle 最终分支 | 将处置结果传给 native/external Provider | 不得跳过 rollback/reset/validate 直接伪造 reusable |
| `PoolBuilder` | properties/setter | typed builder | 不得丢属性别名 |
| `BeforeFilter/AfterFilter` | Filter hook | async 拆分 | 不得丢事件 |
| `ParameterizedSql`、fingerprint | parameterized visitor/stat key | Rust 值对象 | 结果必须与 Java 对齐 |
| `SqlHint`、`DataSourceGroup` | HA selector/node group | async context/ArcSwap | 不得丢粘性与恢复 |
| OpenMetrics exporter | MBean/StatService | 协议替换 | 不得丢属性和管理动作 |
