### 本文档执行责任

五项检查，缺一不可：

1. **Java 名称**：保留公共概念名，不做语义缩写；
2. **文件名**：acronym-aware `snake_case.rs`（`SQLUtils` → `sql_utils.rs`，`DruidDataSource` → `druid_data_source.rs`）；
3. **目录**：保留 Java 包末 2 段；仓库既有 `core/` 前缀与 `sql/` 归并作为已登记偏差；
4. **当前路径**：预期路径与实际路径必须可解释；
5. **公开主类型**：一个文件只承载一个 Java 对象的主类型。

## 结论

Java `core` 共 {{JAVA_OBJECTS}} 个对象：**同名命中 {{MATCHED}} 个（全部 `UNVERIFIED`）**，**缺失 {{MISSING}} 个**（其中 {{REPLACED}} 个属于解析器族替换，{{NOT_REPLACED_MISSING}} 个待实现）；Rust 侧另有 {{EXTRA_TABLE_COUNT}} 个同名之外的公开类型（含内部 helper 与 Rust 扩展）。

**关键判断**：同名文件存在**不等于**完成。命中对象缺中文 Java 来源注释、缺语义测试证据、或路径不符合“末两层”规则时，仍然不得升级状态。当前没有任何对象满足 `IMPLEMENTED` 的全部条件。

## 四、命名与结构规则检查

| 检查项 | 事实 | 判定 |
|---|---|---|
| `lib.rs`/`mod.rs` 只做声明/重导出 | `crates/druid/src/lib.rs` 仅 `pub mod` 与 `pub use` | 通过 |
