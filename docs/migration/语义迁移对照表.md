## 测试基线

1. 源用例分母：Java 4758 个 `@Test`；每例必须有处置（`MIRRORED/ADAPTED/SPLIT/MERGED_APPROVED`）与 `MATCH` 证据，`NOT_APPLICABLE/BLOCKED/MISSING` 一律阻断完成。
2. Rust 侧：4529 个测试属性；新增 `crates/druid-test` 作为整仓验收包，承载源码回放与差分。
3. 差分：沿用 `druid-bench/tests/java_rust_*_differential.rs` 与 `docs/verification/rdbc-first/*` 的证据格式，逐例记录 `MATCH/MISMATCH`。
4. 覆盖率：`cargo llvm-cov -p druid --tests --summary-only`；覆盖率只作信号，不作等价证明。
