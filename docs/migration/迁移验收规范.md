## 1. 基线

| 项 | 值 |
|---|---|
| Java 基线 | Alibaba Druid `1.2.28`（本仓库审计 HEAD 见对象表） |
| Rust 基线 | druid-rust workspace HEAD（见对象表） |
| 对象分母 | Java `core`、`druid-admin`、`druid-wrapper` 分模块记录 class/interface/enum/record/annotation；`package-info` 不计；当前新普查只是文件分母，尚未替代完整对象账本 |

| 目标拓扑 | 当前七成员：五个产品 crate + `druid-bench` + `druid-test` 验证成员；核心归属以已批准 ADR-CRATE-003 为准 |

## 2. 对象状态（唯一词表）

| 状态 | 含义 | 计入完成 |
|---|---|---|
| `IMPLEMENTED` | 预期路径、一对象一文件、真实完整逻辑、中文 Java 来源注释、当前语义测试全部具备 | 是 |
| `DEPENDENCY_REUSED` | 固定版本依赖提供精确能力，且记录上游符号、适配器与本地集成测试 | 是 |
| `PLATFORM_NA` | JVM/容器/框架专有能力，附不可迁移证据 | 是 |
| `UNVERIFIED` | 文件或同名类型存在，但注释/边界/测试证据不足 | 否 |
| `PARTIAL` | 有真实行为，但方法、回调、错误、顺序、生命周期或集成语义不完整 | 否 |
| `STUB` | 仅有形状或占位 | 否 |
| `MISSING` | 已核实源行为/对象既无真实实现也无有据可查的复用；单纯缺同名文件只能记未定位映射 | 否 |
| `MISPLACED` | 同名文件存在但不在确定性路径 | 否 |
| `RUST_EXTENSION` | 有意的 Rust 新增能力，不入 Java 分母 | 不适用 |

**禁止**：以同名、manifest 登记、`lib.rs` 重导出、绿色 `cargo test`、覆盖率数字升级状态。

## 3. 证据等级

| 等级 | 证据 | 可声明 |
|---|---|---|
| `V0_STATIC` | 源码/测试清单、调用链、无 stub 扫描 | 结构处置 |
| `V1_RUST_LOCAL` | Rust 单元/集成/文档/编译测试 | Rust 本地行为 |
| `V2_MIRRORED` | 保留具名 Java 用例的输入与断言 | 用例已表达 |
| `V3_GOLDEN_DIFF` | Java 生成的固定夹具被 Rust 比对 | 记录输出一致 |
| `V4_LIVE_DIFF` | 固定版本 Java 与 Rust 执行同一用例 | 记录行为一致 |
| `V5_HOST` | 真实框架/进程/数据库/网络/文件系统 | 指定集成边界可用 |
| `V6_NONFUNCTIONAL` | 模型/变异/属性/fuzz/负载/安全 | 指定非功能属性成立 |
| `V7_ROLLBACK` | 灰度与回滚演练 | 恢复路径可用 |

证据等级**不替代**对象状态。

## 5. 结构与测试红线

1. 一个 `.rs` 只对应一个 Java 对象；`lib.rs`/`mod.rs` 只放声明与重导出；
2. authored `.rs` 超过 800 行阻断完成；501–800 行必须记录 cohesion review；
3. 禁止 stub、空实现、`todo!()`、`unimplemented!()` 充数；
4. 禁止生产代码 wildcard import；
5. 集成/差分/宿主/整仓测试放 `tests/` 或 `crates/druid-test`（`publish = false`）；`#[cfg(test)]` 只放聚焦单测；
6. 覆盖率必须记录范围（生产文件、排除项、feature、目标），且只作信号。

## 6. 完成门禁

1. 已声明范围内无 `MISSING/MISPLACED/STUB/PARTIAL/UNVERIFIED`；
2. 每个 Java 用例有处置且差分 `MATCH`，无 harness failure / not-run；
3. `cargo fmt --check`、`cargo check`（默认与 `--all-features`）、`clippy -D warnings`、`test`、`doc` 全绿；
4. MSRV 1.95 实跑通过；
5. public-api 快照与 SemVer 报告归档；
6. `crates/druid-test` 整仓验收通过；
7. 四份文档与当前 HEAD 同步且无未解析标记。
