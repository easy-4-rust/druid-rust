# JDBC numeric conversion closure — 2026-10-21

The shared standard typed ResultSet integer conversion previously used Rust float-to-integer casts, which silently map NaN to zero and saturate overflowing/infinite values. It now explicitly checks finiteness and the truncated value's i64 range, using an exclusive 2^63 upper bound. Valid finite fractions still truncate toward zero; the exact lower bound and SQL NULL behavior are preserved. Byte/Short/Integer narrowing now returns SQLDataException with SQLState 22003, including the ordinary scalar getter path. Invalid integer text reports 22018; numeric text overflow reports 22003. Messages do not echo column values. Public signatures are unchanged.
