# 设计

- 在 Admin repository 成功提交 batch 后记录与最新投影对应的数值样本；拒绝和过期输入不写历史。
- 全仓最多 4096 个样本，按服务复合身份区分；使用服务端单调时钟做 TTL，客户端采样时间仅作展示。无 SQL 原文、参数、连接地址。
- 保留池活跃/空闲/容量/等待、SQL 执行次数/总耗时/取回/影响行数、Wall 检查/拒绝/违规。首次样本或计数回退的变化量为 null，不生成负速率。
- REST 只读、身份筛选、最多 500 条；采集健康页显示最近样本表和存储范围。
- 维持现有 repository 最新状态预算，短期历史另有固定条数上限；不把该短期历史描述为持久化存储。
- 健康接口按请求采样 Admin 进程常驻物理内存；读取失败返回 null，避免将 repository 预算/已保留字节误当 RSS。采样不进入 SQL 热路径。
