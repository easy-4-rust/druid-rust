# 设计与兼容性

1. 保留深色顶部导航、浅色背景、紧凑表格和小型直方图，增加默认主页、采集健康、驱动与能力；无大 KPI 卡片，无演示说明。
2. 沿用 v1 camelCase DTO，在每条记录补来源、复合身份与 unavailableFields。保留原有数值字段给旧客户端；新 UI 依据字段可用性显示缺失。poll 使用原始返回字段识别缺失，push 依据实际 wire 映射识别能力。全局读取保留部分失败来源；错误不伪装空成功。
3. 数值详情路径兼容，增加 serviceId / datasourceId 查询过滤；不唯一返回 409，绝不选首条。SQL 搜索、阈值在分页前执行；页长有界，未知值排序置后。
4. 采集健康使用现有 repository 的时间、序列、TTL、容量和拒绝计数；未测量的进程内存、未接入的 ACK/队列不填伪造数字。远端节点失败为明确状态。
5. 自动刷新订阅 tick，不重建路由组件；请求采用最后一次结果胜出，卸载后不更新；保留分页、筛选与详情。
6. 原有 Vue 详情字段全部保留，连接/堆栈复用已有 ManagementSource 读取能力并通过 v1 暴露。脱敏与认证继续使用现有中间件。
7. 构建资产在 D 盘，通过可配置构建目录嵌入；默认构建方式继续兼容。测试只在测试文件中使用 fixture，产品没有 fixture 回退。

验证：前端 Node 行为测试、Rust HTTP 合同/现有回归、真实 Admin 进程 UI、三尺寸检查、cargo-llvm-cov。全仓 Java 差分及迁移完整性不由本增量宣称完成。
