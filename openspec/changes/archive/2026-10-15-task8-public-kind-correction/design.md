# Design

The source oracle remains byte-for-byte unchanged. A fixed migration table names the seven permitted inventory corrections by Java FQCN and exact new Rust shape/path. The verifier checks those rows against the accepted values, then substitutes their frozen Task 2 values only while computing the oracle-bound digest. All other inventory columns remain protected by the existing digest and final source-identity check. The final standard-entry check uses the one accepted invalid-authorization canonical path; the frozen Task 3 digest still uses its original path.

`verify_api_shapes` accepts `#[non_exhaustive] pub enum` as an enum declaration. Unit variant detection still requires an actual enum parent and exact `pub Enum::Variant` output. It does not treat `pub const Enum::Alias` as a variant. Current API kind checks remain separate from final adapter/runtime evidence.
